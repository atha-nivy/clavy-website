# CLAVY Website — Kontext für Claude Code

Statische Website (reines HTML, kein Framework), deployed über Vercel. Seiten: `index.html`, `registrierung.html`, `einwilligung.html`, `agb.html`, `widerruf.html`, `datenschutz.html`, `impressum.html`.

## Produktkontext

Bevor du Inhalte auf der Seite änderst, insbesondere alles rund um das Founding-Families-Programm, lies:

- `docs/product/founding-families-concept.md` — das eigentliche Produktkonzept (Ziel, Vorteile, Feedback-Philosophie, Markenversprechen).
- `docs/product/founding-families-technical-assessment.md` — DSGVO-/AI-Act-Einordnung, Domain Model, Domain Events, DB-Schema, Analytics-KPIs und die dazu getroffenen Entscheidungen.

Diese Docs sind die verbindliche Quelle für Formulierungen zu Founding Families (Anzahl ~500, Vorteile, Datenschutz-Versprechen) — nicht neu erfinden oder abweichend formulieren, ohne Rücksprache.
